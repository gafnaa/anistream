# Unduhan

Tambahan desain anime-only: halaman siap ditonton, antrean (aktif/jeda/gagal), kondisi kosong, dan bottom sheet pilihan kualitas.

Akses dari Ruang saya ? Unduhan atau ikon unduh di detail anime. Navbar tetap lima tab.

- Episode siap ditonton: thumbnail, nomor episode, kualitas, ukuran, menu kelola dan aksi putar offline.
- Antrean: progres bytes/persen, estimasi waktu, jeda, lanjutkan dan coba lagi.
- Pilihan kualitas mengikuti ketersediaan episode; ukuran file adalah perkiraan.
- Wi-Fi saja aktif secara default.
- Hapus file melalui menu kelola dengan konfirmasi. Pertahankan antrean saat koneksi terputus.

Ini adalah desain fitur tambahan. Penyimpanan video lokal, pemulihan unduhan, dukungan format/sumber video dan pemutaran file offline perlu dikerjakan saat implementasi.
